# First_data_analytics_project
Modelo de Regresión Lineal Múltiple para la predicción de precios de vivienda utilizando el framework PACE (Google Advanced Data Analytics). Incluye EDA estadístico, ajuste de modelo OLS con Statsmodels y validación rigurosa de supuestos de regresión. Se usó modelos de IA para la creación de los datos, organización del código y redacción del README
